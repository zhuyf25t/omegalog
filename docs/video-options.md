# 视频配置与实测（2026-10-11）

当前交付使用 **可灵 V3 / kling-video-v3**，版本为 **cloud-motion-v3（云海动态版）**。封面、工作区均已重新生成并替换：请求 10 秒、1080p；实际 1916 × 1080、10.04 秒、24 fps、H.264、无音轨。首尾使用同一张插画，关闭多镜头，固定镜头；云团明显漂移、局部鼓起回落，人物保持温柔的小动作。已对照首尾帧并检查云团形态。保留原生视频帧，仅调整 MP4 封装以便网页加载。实际提交的完整提示词保存在 media-prompts.json。

| 模型 | 官方规格 | 当前课程 API 实测 |
| --- | --- | --- |
| 混元 hy-video-v1.5 | 固定 5 秒、720p | 旧版两段背景成功生成过 |
| Vidu q3-pro | 首尾帧 1–16 秒，最高 1080p | 10 秒 1080p 请求返回 HTTP 402 / 401007 |
| Vidu q3-turbo | 首尾帧 1–16 秒，最高 1080p | 同上 |
| 可灵 v2.5-turbo | 5 / 10 秒，首尾帧需 1080p | 同上 |
| 可灵 v3 | 3–15 秒，720p / 1080p / 4K | **10 秒 1080p 两段均成功**；4K 未测试 |

HTTP 402 的原因为相应服务无可用免费体验额度且未开启后付费。它只说明该次模型调用被拒绝，不代表 API 无效或所有模型都不能用。GET /v1/models 返回的 online 只说明平台上线状态，不能证明账户额度可用。

当前已达到原生 1080p。4K 是该模型提供的另一种档位，本次未调用，不能承诺此账户可用。原始插画为 1672 × 941；更大的输出尺寸也不保证新增可靠细节。网页循环播放、生成时长、视频分辨率是三个独立设置。
