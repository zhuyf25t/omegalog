# API Registry

Status: draft  
Owner Agent: api_contract_alignment

The runnable slice uses a frontend `TaskLogApi` port backed by `LocalFolderTaskApi`. Backend Scala files define the same service messages for future HTTP routing. Browser file handles are private to the frontend local adapter; backend APIs use typed workspace ids and storage refs.

## API Rules

- Frontend and backend fields must be aligned through this registry.
- If frontend sends `userToken`, router resolves it to trusted `userId`.
- Backend business API must not trust frontend-provided `userId`.
- Query should not change the world; command may change the world.
- The frontend local adapter may hold browser file handles internally, but handles never cross into React components or backend API messages.
- DeepSeek or any AI provider key must not appear in frontend requests, frontend source, build output, docs, task files, history files, or summary files.
- Daily summaries must be derived from `TaskHistory.listChanges`, not current `WorkspaceSnapshot` alone.
