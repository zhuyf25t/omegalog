# Task History Objects

Status: draft  
Owner Agent: topos_domain_architect  
Last Verified: 2026-05-30

| Object | Fields | Notes |
|---|---|---|
| `TaskChangeEventId` | branded event id | Generated by the IO adapter. |
| `TaskChangeType` | `created`, `updated`, `completed`, `reactivated`, `archived` | Typed event enum. |
| `TaskChangeEvent` | id, type, source API, occurredAt, localDay, timezone, task ids, before/after snapshots, changed fields | Immutable event record. |
| `TaskEventSnapshot` | task id, title, tags, weight, status, deadline, completedAt | Safe summary input snapshot; no file handles. |

Events are stored separately from task files under `.omegalog-system/history/`.
