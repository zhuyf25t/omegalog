# docs/01_product/AGENTS.md

这里存放“用户想做什么”和“产品图到底暗示了什么”。不要在这里直接决定数据库表。

每次从零项目开始，先建立：

- `vision.md`：一句话目标、用户角色、核心价值。
- `user_journeys.md`：用户从哪里来，做什么动作，看到什么结果。
- `ui_reference_images.md`：产品图/截图对应的页面、按钮、核心数据。
- `glossary.md`：业务词汇表。
- `open_questions.md`：未确认问题。

产品图解析时第一反应：这个页面显示什么核心数据？用户动作改变了哪个事实？需要 query 还是 command？
