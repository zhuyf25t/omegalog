# OmegaLog 云间记

保留 zhuyf25t/omegalog 的焦点任务 + 横向列表结构，以及标题、备注、标签、优先级、截止日期、完成/重新开启、搜索、筛选和分页行为。原版源码及历史保存在仓库的 old 分支。

两个页面：#/ 为云海动态封面；#/log 为浅色云海任务工作区。新增/编辑使用模态表单，不增加页面。React + TypeScript + Vite；不依赖后端或账户。

数据：Task 有稳定 id、标题、备注、标签、1–10 优先级、截止时间、创建时间；active 的 completedAt 为 null，done 为 ISO 时间。派生筛选、排序、统计不另存状态。完成与重新开启只改变状态及完成时间。焦点默认按优先级降序、截止时间升序选出。

localStorage 是唯一持久化边界，保存失败显示错误。首次进入显示可编辑的示例任务。损坏数据不自动覆盖，提供原始备份下载。JSON 导出包含全部任务；用户输入只作为文本渲染。

静态插图与两段视频均在 public/media；凭据及生成脚本在项目外。封面高饱和云海，任务页独立浅色云海 + 奶油白阅读表面。暂停控制及 prefers-reduced-motion 使用静态海报。

验证：领域状态转换/筛选/解码测试、TypeScript、生产构建、浏览器增改/完成/筛选/刷新持久化及窄屏检查。
